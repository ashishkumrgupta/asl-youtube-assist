# Qualitative eval protocol stub (AC-1.5)

Status: **scaffold** — not a completed Deaf-led study.

## Purpose

Wire fixtures and a repeatable review checklist for assist gloss, Tier routing empty-states, captions floor, and critical-domain gate. Prepare for a future funded Deaf/HH cohort (AC-1.3/1.4).

## Procedure (stub)

1. Load named caption fixture from `evals/fixtures/` or `fixtures/captions/`.
2. Record: gloss line, Tier A/B chrome text, pack-pending disclosure visible (Y/N).
3. Check: no English-on-the-hands sold as ASL; no human-interpretation badge on assist.
4. Check: captions floor intact; critical gate still blocks unsupervised assist on keyword fixtures.
5. **Do not** score usefulness-vs-captions until real participants + Business/Deaf-user agreed N.

## Outputs

Store reviewer notes under Project `internal/` (QA / Deaf-user review) — not as marketing claims.
